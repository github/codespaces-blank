Reactでレスポンシブデザインに対応する上ではいくつかの対応方法がありますが、それぞれにどのようなメリット/デメリットがあるのでしょうか？


メディアクエリ
- CSSで画面幅ごとの見た目調整
- `@media screen and (max-width: 600px) { ... }`など
- JSで操作することも可能
- `window.matchMedia()`や`useMediaQuery()`
- メリット   
- ほかの手法と比べてパフォーマンスが良い
- ほかの手法と比べてSEOに強い

[【React】useMediaQuery は最終手段にしよう](https://zenn.dev/chot/articles/do-not-use-use-media-query)

ユーザーエージェント判定
- 通信時に得られるデバイス情報で表示を切り替える手法。   
- 新しいデバイスに対応できないなど、判定の信頼性はあまり高くない。

[MDN](https://developer.mozilla.org/ja/docs/Web/HTTP/Guides/Browser_detection_using_the_user_agent)
>メモ: 繰り返します。ユーザーエージェントを調べるのが良いことはめったにありません。問題を解決するには、もっと良い、もっと広く互換性のある方法が見つかるはずです。

PCとスマホでURLを分割
- デバイス毎に別サイトを用意する 
- サイト管理の手間とコストが2倍になる   

[Googleがサポートする3種類のモバイルサイト構築方法](https://www.ajsa.or.jp/seo-chishiki/archives/websitenomobiletaiouhouhou.html)
>しかし、このやり方はGoogleが最も推奨しない手法です。
